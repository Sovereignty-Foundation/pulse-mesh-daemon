# Changelog

The notable changes to the Pulse Mesh reference implementation, by release. `decisions/` carries the decisions.

## 1.0.0-beta (not yet released)

The first release. Across the three repositories it carries the standard (the two byte layouts and their canonical codec, the conformance vectors, the SeqLock ring, the envelope store, the single-slot region and the UDP transport), the daemon (`mesh-hub`, its port protocol, the Rust client, the dev ring and the `pms` tools), the enterprise, HFT and robotics profiles, the C, Python, Node and WebAssembly bindings, the fuzz harness and the three books, each in the repository it belongs to.
