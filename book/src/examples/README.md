# Three examples

<p class="pm-kind"><b>Part opener</b> · for anyone who wants to see Pulse Mesh work before reading about it</p>

Each example ends with something running on your machine, and each is written to be handed to a coding agent as one prompt or followed by hand. Every step names the command and shows what it prints, and every example closes with checks you can run, what happened, and what the code does not do.

1. [Two programs talk through the daemon](two-programs.md): start a daemon, publish from the command line, from two Rust programs, and from Python and Node, and watch every message named by its content.
2. [An agent swarm: a planner hands out jobs, workers answer](agent-swarm.md): a planner and two workers on one mesh, every result checked against its job by hash.
3. [Across a network: encode, verify, send over UDP](/docs/examples/across-a-network.html): one envelope in your hands, then Pulses over UDP between two terminals or two machines, with nothing but the standard.

The first two need the daemon's repository; the third needs only the standard's. Where an example lives in another book, its link goes there.
