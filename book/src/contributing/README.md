<p class="pm-kind"><b>Part opener</b> · for people changing code or documentation</p>

Contributions go through the same gates whether they change code or prose: formatting, lints, the tests, the rustdoc link check, and for the book the structural checks that keep every page reachable, every link resolving, every displayed version equal to the workspace version, and internal process language out of released text.

- [Developer Onboarding](onboarding.md): the workspace, the branch and PR flow, the gates.
- [Documentation style](style.md): the page kinds, the voice, and the review checklist for anything written.
- [Decision log](../explanation/decision-log.md): the decision record under `decisions/` and how to add to it.
